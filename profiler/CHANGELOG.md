# Phantom Profiler 변경 이력

## 미배포

## 0.2.3 (2026-11-27)

- Gradle 실행이 하위 폴더에 쓴 녹화도 Profiler 도구 창 목록에 보이고 삭제할 수 있다. 마지막 녹화를 지우면 빈 폴더도 지운다. (#PR)
- 내부 클래스, 익명 클래스, 람다 프레임(`Outer$Inner`, `Outer$$Lambda`, `lambda$foo$0`)에서 소스로 이동하면 바깥 클래스와 메서드가 열린다. (#PR)
- 같은 실행 구성을 동시에 여러 번 프로파일해도 실행마다 자기 녹화를 연다. (#PR)
- 도구 창의 녹화 상태를 JFR.check로 JVM에서 직접 읽어, IDE 재시작 뒤에도 시작/중지 버튼이 맞게 켜진다. (#PR)
- 녹화를 열 때 JDK·Kotlin 런타임 클래스는 소스 검색에서 빼고, 편집기를 닫으면 검색을 멈춘다. (#PR)

## 0.2.2 (2026-11-26)

- Profiler 도구 창 아이콘을 초록 실행 표시가 붙은 실행 동작 아이콘 대신 플랫폼의 Profiler 도구 창 아이콘(단색 게이지, 20px용 포함)으로 바꿨다. (#112)
