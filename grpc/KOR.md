# Support for gRPC

`dev.phantom.grpc` · [English](./README.md)

gRPC의 인터페이스 정의 언어인 Protocol Buffers(`.proto`) 파일 편집을 지원합니다.

- 키워드, 스칼라 타입, 문자열, 숫자, 주석을 강조합니다. 잘못된 문장은 문법 오류로 표시하고 파일의 나머지는 그대로 해석합니다.
- 메시지, enum, 서비스, rpc와 그 필드, oneof, enum 값, 중첩 타입을 구조 보기로 보여 줍니다.
- 메시지와 enum 타입에 선언으로 이동, 사용처 찾기, 이름 바꾸기가 됩니다. 타입 이름은 `protoc`과 같은 순서로 찾습니다.
  가장 안쪽 메시지부터 바깥 범위를 거쳐 패키지 루트까지 찾고, `.pkg.Type`은 루트에서 시작합니다. 그 파일과 그 파일이
  import한 파일만 찾습니다.
- `import` 경로에서 선언으로 이동하면 import하는 파일 옆의 파일을, 없으면 경로가 import 경로로 끝나는 프로젝트나 라이브러리
  파일을 엽니다(여럿이면 가장 가까운 파일).
- 줄 주석과 블록 주석, 괄호 짝 맞추기.

`.proto` 파일만 읽고 파일을 열기 전에는 아무것도 하지 않습니다. 시작할 때 하는 일도, 네트워크 접근도 없습니다.

아직 없는 것: rpc, grpc-java / grpc-kotlin이 만든 스텁, 구현 클래스 사이 이동, rpc 호출, `.proto`보다 오래된 생성 코드
경고. JetBrains Protocol Buffers 플러그인과 함께 설치할 수 없습니다. 두 플러그인 모두 `.proto` 파일 타입을 등록합니다.

gRPC와 Protocol Buffers는 각 프로젝트의 이름이며, 이 플러그인은 그 프로젝트들과 관계가 없고 보증받지 않았습니다.
