# Support for Markdown 변경 이력

## 미배포

## 0.1.3 (2026-11-27)

- 미리 보기 내용을 EDT가 아닌 백그라운드에서 만들고, 입력이 잠시 멈춘 뒤에 갱신한다. 큰 문서를 편집할 때 입력이 끊기지 않는다. (#PR)
- 코드 펜스 캐시 정리를 EDT가 아닌 백그라운드 스레드에서 한다. (#PR)
- 코드 블록의 실행 줄 표시가 명령이 실행 가능한지 매번 다시 확인하지 않고, 문서가 바뀔 때까지 결과를 재사용한다. (#PR)

## 0.1.2 (2026-11-26)

- Markdown 파일을 새로 열면 편집기만 보인다. 다른 탭에서 마지막에 고른 배치도, 프로젝트를 처음 열 때 README를 미리 보기로 여는 동작도 따르지 않는다. 미리 보기를 켜기 전에는 JCEF를 시작하지 않고, 파일에 저장된 분할·미리 보기 배치는 그대로 쓴다. (#131)
- 표시 이름을 바꿨다: Phantom for Markdown → Support for Markdown. 플러그인 id와 기능은 그대로다. (#136)
