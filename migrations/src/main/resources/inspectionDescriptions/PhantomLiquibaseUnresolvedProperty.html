Reports ${name} in XML changelogs when no changelog property defines it. Properties are looked up in every changelog of the module (<property name="…"/>, YAML property, formatted SQL --property), in liquibase*.properties and in spring.liquibase.parameters.*. Liquibase leaves an undefined placeholder as written, so the SQL runs with a literal ${name}. Upper-case names (environment variables) and JVM system properties are not reported, and the check is off when parameters are set in YAML Spring configuration or in code (setChangeLogParameters).
