Reports Flyway SQL migrations in db/migration (and the locations set with spring.flyway.locations) whose names Flyway skips or rejects, such as V1_init.sql with a single underscore, v1__init.sql with a lower-case prefix or V1__.sql without a description, and two migrations with the same version. Versions compare as numbers, so V1_16, V1.16 and V1.016 are the same version. Gaps between versions are not reported.
