# Phantom Recent Files

`dev.phantom.recentfiles` · [한국어](./KOR.md)

Recent Files (Cmd+E), Recent Locations and the Switcher (Ctrl+Tab), with the list of recently opened and changed files they show.

Based on the IntelliJ Community Recent Files plugin (Apache 2.0), under Phantom's own id. `intellij.recentFiles.plugin` stays as an alias and the
content module names stay the IntelliJ ones, so the platform modules and plugins that depend on them keep working.
Phantom bundles this build instead of the IntelliJ plugin.
