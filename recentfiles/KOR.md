# Phantom Recent Files

`dev.phantom.recentfiles` · [English](./README.md)

최근 파일(Cmd+E), 최근 위치, 스위처(Ctrl+Tab)와 그것들이 보여 주는 최근에 열고 바꾼 파일 목록입니다.

IntelliJ Community의 Recent Files 플러그인(Apache 2.0)을 바탕으로 Phantom의 id로 만든 플러그인입니다. `intellij.recentFiles.plugin`는 별칭으로 남겨 두고
콘텐츠 모듈 이름도 IntelliJ 것을 그대로 써서, 이것에 의존하는 플랫폼 모듈과 플러그인이 그대로 동작합니다. Phantom은 IntelliJ
플러그인 대신 이 빌드를 번들합니다.
