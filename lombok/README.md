# Lombok Support

`dev.phantom.lombok` · [한국어](./KOR.md)

Project Lombok in the editor: the members Lombok generates (getters, setters, constructors, builders, `@Data`, `@Value`, loggers, `val`/`var` and more) resolve, complete and navigate; lombok.config is read; inspections, quick fixes, Delombok and refactorings know Lombok.

Based on the IntelliJ Community Lombok plugin (`plugins/lombok`, Apache 2.0), under Phantom's own id. `Lombook Plugin` stays
as an alias and the content module names stay the IntelliJ ones, so plugins and bundled modules that depend on them
keep working. Phantom bundles this build instead of the IntelliJ plugin.
