# Lombok

`Lombook Plugin` · [한국어](./KOR.md)

Project Lombok in the editor: the members Lombok generates (getters, setters, constructors, builders, `@Data`, `@Value`, loggers, `val`/`var` and more) resolve, complete and navigate; lombok.config is read; inspections, quick fixes, Delombok and refactorings know Lombok.

The IntelliJ Community Lombok plugin (`plugins/lombok`, Apache 2.0), built here so it updates without a new Phantom build. The plugin id
and content module names stay the IntelliJ ones, so plugins and bundled modules that depend on them keep working, and its
version (`262.261027.x`) is above the bundled build: installing it replaces a copy your Phantom still bundles.
