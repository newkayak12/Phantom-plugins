# Lombok

`Lombook Plugin` · [English](./README.md)

에디터의 Project Lombok: Lombok이 만드는 멤버(getter, setter, 생성자, 빌더, `@Data`, `@Value`, 로거, `val`/`var` 등)가 참조·자동완성·이동됩니다. lombok.config를 읽고, 인스펙션·빠른 수정·Delombok·리팩터링이 Lombok을 이해합니다.

IntelliJ Community의 Lombok 플러그인(`plugins/lombok`, Apache 2.0)을 여기서 빌드해, Phantom을 새로 빌드하지 않아도 업데이트됩니다. 플러그인 id와 콘텐츠
모듈 이름은 IntelliJ 것을 그대로 써서 이것에 의존하는 플러그인과 번들 모듈이 그대로 동작합니다. 버전(`262.261027.x`)이 번들 빌드보다 높아,
설치하면 Phantom에 아직 번들된 사본을 대신합니다.
