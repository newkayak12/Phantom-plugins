# Support for Lombok
`dev.phantom.lombok` · [English](./README.md)

에디터의 Project Lombok: Lombok이 만드는 멤버(getter, setter, 생성자, 빌더, `@Data`, `@Value`, 로거, `val`/`var` 등)가 참조·자동완성·이동됩니다. lombok.config를 읽고, 인스펙션·빠른 수정·Delombok·리팩터링이 Lombok을 이해합니다.

IntelliJ Community의 Lombok 플러그인(`plugins/lombok`, Apache 2.0)을 바탕으로 Phantom의 id로 만든 플러그인입니다. `Lombook Plugin`는 별칭으로
남겨 두고 콘텐츠 모듈 이름도 IntelliJ 것을 그대로 써서, 이것에 의존하는 플러그인과 번들 모듈이 그대로 동작합니다. Phantom은
IntelliJ 플러그인 대신 이 빌드를 번들합니다.
