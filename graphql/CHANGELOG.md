# Support for GraphQL 변경 이력

## 미배포

## 0.1.0 (2026-11-27)

- 첫 배포. `.graphql`, `.graphqls`, `.gql` 파일의 하이라이팅, 타입과 프래그먼트로 이동, 사용처 찾기, 이름 바꾸기를 지원한다. (#PR)
- 스키마 필드와 Spring GraphQL 핸들러(`@QueryMapping`, `@MutationMapping`, `@SubscriptionMapping`, `@SchemaMapping`, `@BatchMapping`)를 거터 아이콘으로 오가고, 핸들러 없는 `Query`·`Mutation`·`Subscription` 필드를 경고한다. (#PR)
