# Support for Mermaid 변경 이력

## 미배포

## 0.1.6 (2026-11-27)

- 식별자 선언을 파일이 바뀔 때까지 캐시해 큰 다이어그램에서 하이라이팅과 이동이 빨라졌습니다 (#178)
- 같은 식별자가 자동 완성 목록에 한 번만 나옵니다 (#178)
- 미리보기가 입력, 테마, 설정 변경을 한 번에 하나씩 그려 오래된 다이어그램이나 테마가 남지 않습니다 (#178)
- 에디터 색 구성표를 바꾸면 열린 Mermaid 파일의 테마 검사가 다시 실행됩니다 (#178)

## 0.1.5 (2026-11-26)

- Mermaid 파일을 새로 열면 편집기만 보인다. 다른 탭에서 마지막에 고른 배치도 따르지 않는다. 미리 보기를 처음 보일 때 JCEF 브라우저를 만들고, 파일에 저장된 분할·미리 보기 배치는 그대로 쓴다. (#131)
- 표시 이름을 바꿨다: Phantom for Mermaid → Support for Mermaid. 플러그인 id와 기능은 그대로다. (#136)
