# YAML

`org.jetbrains.plugins.yaml` · [English](./README.md)

YAML 파일: 하이라이팅, 포매팅, 접기, 구조 보기, 브레드크럼, 앵커와 별칭, 인스펙션과 인텐션, JSON Schema 기반 자동완성·검증·문서. Phantom의 docker, kubernetes, openapi, migrations 플러그인이 이것에 의존합니다.

IntelliJ Community의 YAML 플러그인(`plugins/yaml`, Apache 2.0)을 여기서 빌드해, Phantom을 새로 빌드하지 않아도 업데이트됩니다. 플러그인 id와 콘텐츠
모듈 이름은 IntelliJ 것을 그대로 써서 이것에 의존하는 플러그인과 번들 모듈이 그대로 동작합니다. 버전(`262.261027.x`)이 번들 빌드보다 높아,
설치하면 Phantom에 아직 번들된 사본을 대신합니다.
