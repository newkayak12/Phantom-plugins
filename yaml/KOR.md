# Phantom YAML

`dev.phantom.yaml` · [English](./README.md)

YAML 파일: 하이라이팅, 포매팅, 접기, 구조 보기, 브레드크럼, 앵커와 별칭, 인스펙션과 인텐션, JSON Schema 기반 자동완성·검증·문서. Phantom의 docker, kubernetes, openapi, migrations 플러그인이 이것에 의존합니다.

IntelliJ Community의 YAML 플러그인(`plugins/yaml`, Apache 2.0)을 바탕으로 Phantom의 id로 만든 플러그인입니다. `org.jetbrains.plugins.yaml`는 별칭으로
남겨 두고 콘텐츠 모듈 이름도 IntelliJ 것을 그대로 써서, 이것에 의존하는 플러그인과 번들 모듈이 그대로 동작합니다. Phantom은
IntelliJ 플러그인 대신 이 빌드를 번들합니다.
