# Phantom Rainbow

`dev.phantom.rainbow` · [한국어](./KOR.md)

- **Brackets:** `()`, `[]` and `{}` colored by how deeply they are nested, each kind counted on its own, in every
  language whose brackets the IDE matches. A bracket is colored only when its partner belongs to the same element, so
  `<` and `>` as comparison operators stay as they are.
- **Indentation:** the indentation of each line colored by level, one band per indent level as wide as the file's indent
  size (Code Style); a tab counts to the next tab stop.

Turn either off under **Settings | Editor | Rainbow**; change the colors under **Editor | Color Scheme | Rainbow**.
Replaces Rainbow Brackets and Indent Rainbow (Phantom does not load them together).
