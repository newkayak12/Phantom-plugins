# Phantom Properties

`dev.phantom.properties` · [English](./README.md)

`.properties` 파일과 XML properties 파일: 하이라이팅, 포매팅(원하면 열 맞춤), 접기, 주석 처리, 자동완성, 키의 사용처 찾기와 이름
바꾸기, Resource Bundle 편집기와 New Resource Bundle, Project 뷰의 번들 묶음 표시, 구조 뷰, 사용하지 않거나 중복되거나 불완전하거나
정렬되지 않은 속성, 끝 공백, 키/값 구분자, 말줄임표를 잡는 인스펙션, 구조 검색, properties를 이해하는 diff와 병합, 맞춤법 검사,
저작권 헤더. Java 국제화, Spring Boot, Grazie, Groovy, Gradle, Maven이 이 플러그인 위에서 동작합니다.

IntelliJ Community의 Properties 플러그인(`plugins/properties`, Apache 2.0)을 바탕으로 Phantom의 id로 만든 플러그인입니다.
`com.intellij.properties`는 별칭으로 남겨 두고 콘텐츠 모듈 이름도 IntelliJ 것을 그대로 써서, 이것에 의존하는 플러그인과 번들
모듈이 그대로 동작합니다. Phantom은 IntelliJ 플러그인 대신 이 빌드를 번들합니다.
