# Phantom Properties

`dev.phantom.properties` · [한국어](./KOR.md)

`.properties` files and XML properties files: highlighting, formatting (aligned in columns if you like), folding,
commenting, completion, find usages and rename of keys, the Resource Bundle editor and New Resource Bundle, grouping of
bundles in the Project view, a structure view, inspections for unused, duplicate, incomplete and unsorted properties,
trailing spaces, key/value delimiters and ellipses, structural search, a diff and merge that understand properties,
spellchecking and copyright headers. Java internationalization, Spring Boot, Grazie, Groovy, Gradle and Maven build on it.

Based on the IntelliJ Community Properties plugin (`plugins/properties`, Apache 2.0), under Phantom's own id.
`com.intellij.properties` stays as an alias and the content module names stay the IntelliJ ones, so plugins and bundled
modules that depend on them keep working. Phantom bundles this build instead of the IntelliJ plugin.
