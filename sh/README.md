# Phantom Shell Script

`dev.phantom.sh` · [한국어](./KOR.md)

Shell scripts: highlighting, completion, rename, quick documentation, a Shell Script run configuration, ShellCheck inspections and shfmt formatting (each downloaded on first use), shell code blocks in Markdown and the terminal, and copyright headers.

Based on the IntelliJ Community Shell Script plugin (`plugins/sh`, Apache 2.0), under Phantom's own id. `com.jetbrains.sh` stays
as an alias and the content module names stay the IntelliJ ones, so plugins and bundled modules that depend on them
keep working. Phantom bundles this build instead of the IntelliJ plugin.
