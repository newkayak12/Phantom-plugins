# Shell Script

`com.jetbrains.sh` · [한국어](./KOR.md)

Shell scripts: highlighting, completion, rename, quick documentation, a Shell Script run configuration, ShellCheck inspections and shfmt formatting (each downloaded on first use), shell code blocks in Markdown and the terminal, and copyright headers.

The IntelliJ Community Shell Script plugin (`plugins/sh`, Apache 2.0), built here so it updates without a new Phantom build. The plugin id
and content module names stay the IntelliJ ones, so plugins and bundled modules that depend on them keep working, and its
version (`262.261027.x`) is above the bundled build: installing it replaces a copy your Phantom still bundles.
