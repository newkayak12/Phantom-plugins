# Shell Script

`com.jetbrains.sh` · [English](./README.md)

셸 스크립트: 하이라이팅, 자동완성, 이름 바꾸기, 빠른 문서, Shell Script 실행 구성, ShellCheck 인스펙션과 shfmt 포매팅(처음 쓸 때 내려받음), Markdown과 터미널의 셸 코드 블록, 저작권 헤더.

IntelliJ Community의 Shell Script 플러그인(`plugins/sh`, Apache 2.0)을 여기서 빌드해, Phantom을 새로 빌드하지 않아도 업데이트됩니다. 플러그인 id와 콘텐츠
모듈 이름은 IntelliJ 것을 그대로 써서 이것에 의존하는 플러그인과 번들 모듈이 그대로 동작합니다. 버전(`262.261027.x`)이 번들 빌드보다 높아,
설치하면 Phantom에 아직 번들된 사본을 대신합니다.
