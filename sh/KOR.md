# Phantom Shell Script

`dev.phantom.sh` · [English](./README.md)

셸 스크립트: 하이라이팅, 자동완성, 이름 바꾸기, 빠른 문서, Shell Script 실행 구성, ShellCheck 인스펙션과 shfmt 포매팅(처음 쓸 때 내려받음), Markdown과 터미널의 셸 코드 블록, 저작권 헤더.

IntelliJ Community의 Shell Script 플러그인(`plugins/sh`, Apache 2.0)을 바탕으로 Phantom의 id로 만든 플러그인입니다. `com.jetbrains.sh`는 별칭으로
남겨 두고 콘텐츠 모듈 이름도 IntelliJ 것을 그대로 써서, 이것에 의존하는 플러그인과 번들 모듈이 그대로 동작합니다. Phantom은
IntelliJ 플러그인 대신 이 빌드를 번들합니다.
