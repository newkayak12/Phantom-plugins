# Support for Groovy Live Templates
`dev.phantom.groovy-live-templates` · [한국어](./KOR.md)

The `groovyScript()` live template macro: a template variable computed by a Groovy script, inline or from a file, with
the macro's other arguments (`_1`, `_2`, ...) and the current editor (`_editor`) at hand.

Based on the IntelliJ Community Groovy Live Templates plugin (`plugins/groovy-live-templates`, Apache 2.0), under
Phantom's own id. `org.intellij.groovy.live.templates` stays as an alias. Phantom bundles this build instead of the
IntelliJ plugin.
