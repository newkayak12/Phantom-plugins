Reports a call of a built-in function with a number of arguments it does not take, such as NULLIF(a) or IFNULL(a, b, c). The function list is curated per dialect (MySQL and MariaDB, PostgreSQL, H2); with no data source only NULLIF, COALESCE, LOWER, UPPER and ABS are checked. Special forms such as SUBSTRING(x FROM 1) and qualified calls of user functions are left alone.
