Reports a JPA entity whose table is not in the database of the project's data source.

The table name is the one Hibernate uses: @Table(name), or the entity name, turned into a physical name by the naming strategy the configuration sets (Spring Boot's default puts _ between words and lower-cases; PhysicalNamingStrategyStandardImpl keeps names as written). A SINGLE_TABLE subclass uses its root's table.

Runs only when the project has a data source that the configuration's spring.datasource.url points to (or the only data source, when the configuration names none). The schema is read when needed, in the background, into the cache the Database tool window uses; nothing is reported until it is loaded.
