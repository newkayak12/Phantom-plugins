Reports COPY and ADD here-documents (COPY <<EOF /etc/app.conf) that BuildKit rejects:
  • no destination path after the here-document;
  • combined with --from, which copies from another stage or image;
  • a # syntax=docker/dockerfile:1.3 (or older) directive: here-documents need syntax 1.4 or later (the -labs channels are fine).
Without a syntax directive the builder's built-in frontend is used, which supports here-documents in current Docker releases.
