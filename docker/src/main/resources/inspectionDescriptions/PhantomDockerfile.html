Reports what the Docker builder rejects or reads differently than written: unknown instructions; an indented line after an instruction that does not end with \; wrong argument counts for FROM, COPY, ADD, WORKDIR, USER and others; malformed ENV, LABEL and ARG; SHELL and exec forms that are not JSON arrays (single quotes make the builder run them as shell text); unclosed heredocs; duplicate stage names; COPY --from with the index of the current or a later stage.
