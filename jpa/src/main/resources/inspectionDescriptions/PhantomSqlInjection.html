Reports query text built from a value that is not a constant, passed to JDBC (Statement, Connection.prepareStatement), Spring JdbcTemplate/NamedParameterJdbcTemplate/JdbcClient/DatabaseClient, or JPA/Hibernate createQuery/createNativeQuery: string concatenation, Kotlin string templates and String.format. Pass the value as a bind parameter (?, :name) instead.

Numbers, booleans, enums and constants are not reported. A local variable is followed back to its initializer once; values assembled with a StringBuilder or passed through other methods are not traced.
