Reports Kotlin entities that clash with the compiler plugins the module's Gradle build applies: final entities without allOpen, missing no-argument constructors without kotlin("plugin.jpa"), redundant open and constructors, data class entities, val attributes and read-only collection types on associations. The compiler plugin checks are silent in modules without a Gradle build script.

Also reports a non-null Kotlin type on an attribute mapped as nullable (@Column(nullable = true), @JoinColumn(nullable = true), @ManyToOne(optional = true)): a NULL in the column puts null into a property Kotlin treats as never null.
