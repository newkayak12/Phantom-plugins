Reports injecting a bean by its class when that bean is a JDK dynamic proxy: Spring then exposes only the bean's interfaces, and startup fails with "the bean is of type $ProxyNN".

Only reported when interface-based proxies are chosen explicitly: with Spring Boot, spring.aop.proxy-target-class=false; without Boot, an @Enable* annotation (@EnableTransactionManagement, @EnableAsync, @EnableCaching, @EnableAspectJAutoProxy) with proxyTargetClass = false and none with true. The bean must be proxied (transactions, async, caching, retry) and implement an interface.
