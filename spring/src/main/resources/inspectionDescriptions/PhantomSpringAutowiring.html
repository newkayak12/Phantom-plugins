Reports injection points that Spring could not satisfy at startup.
  • No bean: no bean of the injected type is declared in project sources, but a class that could be one exists (for example, an implementation without @Component).
  • More than one bean: several beans match and neither a qualifier, a single @Primary bean, nor the parameter name picks one. Quick fixes add @Qualifier to the injection point or @Primary to a bean.

Only types declared in project sources are checked; beans from libraries and auto-configuration are not modeled. Optional injection (required = false, nullable types, Kotlin default values, collections, Optional, ObjectProvider) and test sources are skipped.
