Reports @Value strings whose placeholder syntax is broken, so Spring injects them as literal text or fails:
  • a space between $ and {: $ {app.name}
  • a placeholder that never closes: ${app.name
  • an empty placeholder: ${}
  • an expression inside a placeholder: ${#{...}} — placeholders resolve first, so write #{${...}}
  • a bare {app.name} that probably lost its $
