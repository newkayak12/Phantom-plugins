Reports request mappings that declare an API version (Spring Framework 7) in a project where nothing configures API versioning: no configureApiVersioning in a WebMvcConfigurer or WebFluxConfigurer, no ApiVersionStrategy of its own and no spring.mvc.apiversion.* / spring.webflux.apiversion.* setting. Spring then refuses to start because it cannot tell which version a request asks for.

Only active when the API versioning classes of Spring Framework 7 are on the classpath.
