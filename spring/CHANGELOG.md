# Support for Spring 변경 이력

## 미배포

## 0.9.10 (2026-11-28)

- 고스트 모드에서는 Spring 검사와 거터 아이콘을 끈다. SpEL과 `${...}` 플레이스홀더 색칠, 완성, 이동은 그대로다. (#PR)

## 0.9.9 (2026-11-27)

- Endpoints 목록이 추상 기반 컨트롤러에서 상속한 매핑과, 합성 애너테이션에 담긴 클래스의 `@RequestMapping`을 읽는다. (#170)
- `@EnableMethodSecurity`를 담은 합성 애너테이션을 쓴 설정도 메서드 보안 검사가 인식한다. 선언만 하고 쓰지 않은 합성 애너테이션은 켠 것으로 보지 않는다. (#170)
- `@Qualifier("name")`를 담은 사용자 애너테이션이 붙은 주입 지점도 그 이름의 빈으로 이동한다. (#170)
- 빈에서 주입 지점으로 가는 거터가 `javax.sql.DataSource` 같은 라이브러리 상위 타입으로 주입된 곳도 찾는다. (#170)
- 메시징 리스너·전송 지점의 `${...}` 자리표시자가 저장하지 않은 설정 파일 편집도 반영한다. (#170)
- 메시징 목록, 메서드 보안 검사, JDK 프록시 판별이 다른 언어 파일이나 메서드 본문을 입력할 때마다 프로젝트 전체를 다시 찾지 않는다. AOP 어드바이스 거터는 이름 붙은 포인트컷을 어드바이스마다 한 번만 해석하고, 이벤트 거터는 느린 마커 단계에서 호출을 해석한다. (#170)
- Spring Beans 도구 창이 PSI를 직접 붙잡지 않고, 같은 노드를 여러 번 펼쳐도 검색을 한 번만 한다. (#170)

## 0.9.8 (2026-11-26)

- 표시 이름을 바꿨다: Phantom for Spring → Support for Spring. 플러그인 id와 기능은 그대로다. (#136)

## 0.9.7 (2026-11-24)

- 캐시 거터 아이콘, 이벤트 리스너 거터 아이콘, 캐시 이름·AOP 자동 프록시·API 버전 검사가 메서드 본문을 입력할 때마다 프로젝트 전체를 다시 찾지 않는다. 선언이 바뀔 때만 다시 찾는다. (#128)
- Spring Beans 도구 창 아이콘에 20px용 그림을 더해, 새 UI 스트라이프에서 늘려 그려 흐려지지 않는다. (#112)
- Spring MVC 엔드포인트 목록, AOP 어드바이스 거터, `@Autowired` 빈 밖 검사와 자동 주입 검사가 메서드 본문이나 다른 언어 파일을 입력할 때마다 프로젝트 전체를 다시 찾지 않는다. 선언이 바뀔 때만 다시 찾는다. (#119)
- IntelliJ IDEA Ultimate가 만든 프로젝트를 열 때 "Unknown facet type: 'web'" 오류 알림이 더 이상 뜨지 않는다. .iml의 Web facet 설정은 그대로 남아 Ultimate에서도 읽힌다. (#111)
