# Phantom TOML

`dev.phantom.toml` · [English](./README.md)

TOML 파일: 하이라이팅, 포매팅, 접기, 키와 테이블 사이의 참조, Expand Inline Table 인텐션, JSON Schema 기반 자동완성과 문서, Natural Languages가 켜져 있으면 주석과 문자열 교정. Gradle 버전 카탈로그(`libs.versions.toml`) 지원이 이 플러그인을 씁니다.

IntelliJ Community의 TOML 플러그인(`plugins/toml`, Apache 2.0)을 바탕으로 Phantom의 id로 만든 플러그인입니다. `org.toml.lang`는 별칭으로
남겨 두고 콘텐츠 모듈 이름도 IntelliJ 것을 그대로 써서, 이것에 의존하는 플러그인과 번들 모듈이 그대로 동작합니다. Phantom은
IntelliJ 플러그인 대신 이 빌드를 번들합니다.
