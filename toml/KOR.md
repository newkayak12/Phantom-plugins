# Toml

`org.toml.lang` · [English](./README.md)

TOML 파일: 하이라이팅, 포매팅, 접기, 키와 테이블 사이의 참조, Expand Inline Table 인텐션, JSON Schema 기반 자동완성과 문서, Natural Languages가 켜져 있으면 주석과 문자열 교정. Gradle 버전 카탈로그(`libs.versions.toml`) 지원이 이 플러그인을 씁니다.

IntelliJ Community의 Toml 플러그인(`plugins/toml`, Apache 2.0)을 여기서 빌드해, Phantom을 새로 빌드하지 않아도 업데이트됩니다. 플러그인 id와 콘텐츠
모듈 이름은 IntelliJ 것을 그대로 써서 이것에 의존하는 플러그인과 번들 모듈이 그대로 동작합니다. 버전(`262.261027.x`)이 번들 빌드보다 높아,
설치하면 Phantom에 아직 번들된 사본을 대신합니다.
