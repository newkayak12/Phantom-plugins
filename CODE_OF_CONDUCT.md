# Code of conduct

Be respectful in this repository's issues, pull requests, reviews and discussions. Discuss code and evidence; avoid harassment, discriminatory language, personal attacks, threats and disclosure of private information. Give constructive feedback and respect different levels of experience.

The [maintainer](https://github.com/newkayak12) may moderate comments, close disruptive threads or restrict participation to protect contributors. Report concerns using a private contact method published on the maintainer's profile; if none is listed, ask for a private channel without posting personal details. No response deadline is promised.

This is the Phantom-plugins project's policy. It does not place this independently maintained project under JetBrains governance or change upstream license and attribution notices.
