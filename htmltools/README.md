# Phantom HTML Tools

`dev.phantom.htmltools` · [한국어](./KOR.md)

HTML editing: inspections for deprecated tags and attributes, accessibility (missing `alt`, `lang`, `title`, form labels), image sizes and unreachable web links, with quick fixes; an Update Image Size intention, table column actions and cell navigation, Go to Symbol for element ids, Extract Include, references between HTML files, and image drag and drop into HTML.

Based on the IntelliJ Community HTML Tools plugin (`plugins/htmltools`, Apache 2.0), under Phantom's own id. `HtmlTools` stays
as an alias, so plugins that depend on it keep working. Phantom bundles this build instead of the IntelliJ plugin.
