# Phantom HTML Tools

`dev.phantom.htmltools` · [English](./README.md)

HTML 편집: 더 이상 쓰지 않는 태그와 속성, 접근성(`alt`, `lang`, `title`, 폼 레이블 누락), 이미지 크기, 열리지 않는 웹 링크를 찾는 인스펙션과 빠른 수정, Update Image Size 인텐션, 표 열 추가와 셀 이동, 요소 id로 Go to Symbol, Extract Include, HTML 파일 사이 참조, HTML로 이미지 끌어 놓기.

IntelliJ Community의 HTML Tools 플러그인(`plugins/htmltools`, Apache 2.0)을 바탕으로 Phantom의 id로 만든 플러그인입니다. `HtmlTools`는 별칭으로
남겨 두어, 이것에 의존하는 플러그인이 그대로 동작합니다. Phantom은 IntelliJ 플러그인 대신 이 빌드를 번들합니다.
