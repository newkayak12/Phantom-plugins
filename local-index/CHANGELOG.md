# Phantom Local Index 변경 이력

## 미배포

- 같은 컴퓨터의 체크아웃 사이에서 인덱스를 재사용하기 위한 플러그인 뼈대를 추가했다. 아직은 인덱스에 손대지 않고 그대로 통과시킨다. (#?)
- 재사용할 수 있는 인덱스를 파일 내용만으로 결과가 정해지는 것(IdIndex, Java 식 인덱스, Trigram, Kotlin 소스 이름 인덱스, Java 스텁)으로 한정했다. 아직은 데이터를 재사용하지 않는다. (#?)
- 같은 파일 내용을 이미 인덱싱한 다른 체크아웃이 있으면 IdIndex와 Java 식 인덱스 데이터를 다시 계산하지 않고 재사용한다. 저장하지 않은 편집은 캐시를 거치지 않는다. (#?)
- 같은 파일 내용을 이미 인덱싱한 다른 체크아웃이 있으면 Java 스텁을 다시 만들지 않고 재사용한다. (#?)
- 같은 파일 내용을 이미 인덱싱한 다른 체크아웃이 있으면 Kotlin(.kt) 스텁도 다시 만들지 않고 재사용한다. 스크립트(.kts)는 제외한다. (#?)
