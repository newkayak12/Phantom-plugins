# Support for Ktor 변경 이력

## 미배포

## 0.1.4 (2026-11-26)

- 표시 이름을 바꿨다: Phantom for Ktor → Support for Ktor. 플러그인 id와 기능은 그대로다. (#136)
- Ktor 라우트 목록(Endpoints 보기)이 YAML 등 JVM 코드가 아닌 파일을 입력할 때마다 다시 계산되지 않는다. (#119)

## 0.1.3 (2026-11-22)

- 이름을 바꿨다: Ktor Support → Phantom for Ktor. Phantom으로 시작하고, 지원하는 프로젝트 이름은 뒤에 둔다. 플러그인 id와 기능은 그대로다.

## 0.1.2 (2026-11-20)

- 플러그인 jar에 `LICENSE`, `NOTICE`와 서드파티 라이선스 고지를 넣었다. (#45)
