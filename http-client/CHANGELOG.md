# Phantom HTTP Client 변경 이력

## 미배포

## 0.2.2 (2026-11-27)

- Stop 링크와 실행 중인 탭 닫기가 요청을 실제로 멈춘다. 본문을 읽는 중에도 멈추고, 응답 처리 스크립트도 중단된다. (#PR)
- `# @timeout`이 없는 요청은 60초 안에 응답이 없으면 실패한다. (#PR)
- 끝없이 재귀하는 응답 처리 스크립트는 호출 깊이 오류로 보고되고, 스크립트 오류가 나도 응답 창이 "Sending…"에 머물지 않는다. (#PR)
- 1 MB를 넘는 응답 본문은 정리하지 않고 일반 텍스트로 보여 준다. (#PR)
- 환경을 바꾸거나 저장하지 않은 env 파일을 고치면 미해결 변수 경고가 바로 갱신된다. (#PR)
- 아직 값을 만들지 못하는 `$auth.token(...)`을 자동 완성에서 뺐다. (#PR)
- 파일 변수 이름 바꾸기(Rename)가 선언과 `{{...}}` 참조를 함께 바꾼다. (#PR)
- 큰 `.http` 파일에서 변수 검사와 import 해석을 파일 단위로 캐시해 편집이 가벼워졌다. (#PR)

## 0.2.1 (2026-11-20)
