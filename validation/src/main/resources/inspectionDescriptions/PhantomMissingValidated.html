Reports Spring services, components and repositories with constraints or @Valid on method parameters or return values but no @Validated on the class or its supertypes. Spring checks method constraints only for @Validated beans. Stereotypes of the project's own (an annotation meta-annotated with @Service or @Component) count too. Controllers are reported only before Spring Framework 6.1 and only for constraints on parameters: Spring MVC validates @Valid arguments itself, and since 6.1 all controller parameter constraints.
