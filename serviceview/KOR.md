# Services View

`dev.phantom.serviceview` · [English](./README.md)

서비스 도구 창: 실행 구성(실행 대시보드), 서버, 데이터베이스, Docker 등 서비스를 한 트리에 모으고 각자 출력 탭을 둡니다. 트리 위의 바는 Phantom의 Navigation Bar를 씁니다.

IntelliJ Community의 Services View 플러그인(Apache 2.0)을 바탕으로 Phantom의 id로 만든 플러그인입니다. `intellij.execution.serviceView.plugin`는 별칭으로 남겨 두고
콘텐츠 모듈 이름도 IntelliJ 것을 그대로 써서, 이것에 의존하는 플랫폼 모듈과 플러그인이 그대로 동작합니다. Phantom은 IntelliJ
플러그인 대신 이 빌드를 번들합니다.
