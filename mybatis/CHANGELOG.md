# Phantom for MyBatis 변경 이력

## 미배포

- 매퍼 인터페이스의 XML 파일 찾기를 PSI가 바뀔 때까지 캐시해서, 거터 아이콘과 검사가 메서드마다 인덱스를 다시 조회하지 않는다. MyBatis가 없는 프로젝트의 인터페이스 편집도 가벼워진다.

## 0.3.3 (2026-11-22)

- 이름을 바꿨다: MyBatis Support → Phantom for MyBatis. Phantom으로 시작하고, 지원하는 프로젝트 이름은 뒤에 둔다. 플러그인 id와 기능은 그대로다.
