# Phantom Modal Commit

`dev.phantom.modalcommit` · [한국어](./KOR.md)

The modal commit dialog for Git and Mercurial, instead of the Commit tool window: **Settings | Advanced Settings |
Version Control | Use modal commit interface for Git and Mercurial**. On the first start the setting follows the
"Use non-modal commit interface" choice you had.

Ported from the IntelliJ Community Modal Commit Interface (`plugins/git-modal-commit`, Apache 2.0) with its own setting
id, so it updates without a new Phantom build. Turn the bundled Modal Commit Interface off if your Phantom still bundles it.
