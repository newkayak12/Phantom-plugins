# Phantom Modal Commit

`dev.phantom.modalcommit` · [English](./README.md)

Git과 Mercurial에서 Commit 도구 창 대신 모달 커밋 대화상자를 씁니다. **Settings | Advanced Settings | Version Control |
Use modal commit interface for Git and Mercurial**에서 켭니다. 처음 시작할 때는 기존 "Use non-modal commit interface" 설정을 따릅니다.

IntelliJ Community의 Modal Commit Interface(`plugins/git-modal-commit`, Apache 2.0)를 설정 id만 바꿔 옮겨 왔습니다.
그래서 Phantom을 새로 빌드하지 않아도 업데이트됩니다. Phantom에 번들 Modal Commit Interface가 아직 있다면 그쪽은 꺼 주세요.
