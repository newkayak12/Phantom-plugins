# Phantom Settings Repository

`dev.phantom.sync` · [한국어](./KOR.md)

Backup and Sync to a git repository you own (GitHub or any git remote) instead of a JetBrains account. It plugs into the platform's Backup and Sync as one more provider: settings are pushed and pulled as a snapshot on a branch of that repository with your own git credentials, and nothing is sent anywhere else.

Phantom bundles this plugin. Until 0.1.0 Phantom built it from its own repository (`plugins/phantom-sync`).
