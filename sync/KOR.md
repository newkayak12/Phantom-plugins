# Phantom Settings Repository

`dev.phantom.sync` · [English](./README.md)

JetBrains 계정 대신 내가 가진 git 저장소(GitHub나 다른 git 원격)로 Backup and Sync를 합니다. 플랫폼의 Backup and Sync에 제공자 하나로 붙습니다. 설정은 그 저장소의 브랜치에 스냅샷으로 올리고 받으며, 내 git 인증 정보를 쓰고 다른 곳으로는 아무것도 보내지 않습니다.

Phantom에 번들됩니다. 0.1.0 전에는 Phantom 저장소(`plugins/phantom-sync`)에서 빌드했습니다.
