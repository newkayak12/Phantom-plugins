# Phantom Key-Value Console 변경 이력

## 미배포

## 0.1.5 (2026-11-27)

- TLS 연결이 서버 인증서의 호스트 이름을 확인하고 SNI를 보낸다. 전에는 신뢰할 수 있는 인증서면 다른 호스트용이어도 받아들였다. (#169)
- 콘솔의 SELECT는 보내지 않고 서버 설정(Edit Server…)에서 데이터베이스를 바꾸라고 알린다. 전에는 키 목록이 쓰는 연결의 데이터베이스가 말없이 바뀌었다. (#169)
- 서버 설정을 고치면 열린 연결을 닫아, 다음 명령부터 바뀐 호스트·포트·사용자·데이터베이스·TLS로 연결한다. (#169)
- 콘솔의 `\xNN`은 바이트 하나로 보내고(0x80 이상이 두 바이트로 가던 문제), 16진수가 아닌 `\x`는 오류 없이 `x`로 남긴다. (#169)
- 키 목록 SCAN은 5초 또는 1,000번 호출에서 멈추고 키가 더 있다고 알린다. 새 요청이 오면 이전 검색은 멈추고 늦게 온 응답은 버린다. (#169)
- 1 MiB보다 큰 문자열 값은 앞부분만 읽고 전체 크기를 보여 준다. 콘솔 응답은 1,000줄까지 보여 주고 출력 창은 끝 부분만 남긴다. (#169)
- 키 타입이 바뀌는 등 서버가 오류로 답하면 ClassCastException 대신 서버의 오류 메시지를 보여 준다. RESP3 속성(`|`)과 큰 수(`(`) 응답을 읽는다. (#169)

## 0.1.4 (2026-11-26)

- Redis 도구 창 아이콘을 데이터베이스와 헷갈리던 원통 대신 번개(인메모리 캐시)로 바꿨다. (#112)
- 서버를 저장하거나 지울 때 비밀번호 저장소(OS 키체인) 쓰기를 백그라운드에서 해서, 키체인이 느리거나 확인을 물어도 IDE가 멈추지 않는다. (#120)

## 0.1.3 (2026-11-22)

- 콘솔에 입력한 FLUSHDB·FLUSHALL은 대상 서버와 삭제 범위를 보여 주고 확인을 받은 뒤에만 보낸다. 취소하면 아무것도 보내지 않는다. (#64)
- 콘솔에 입력한 비밀번호(AUTH, HELLO AUTH, MIGRATE AUTH/AUTH2, ACL SETUSER, CONFIG SET requirepass/masterauth)를 출력에서 `***`로 가리고 히스토리에 남기지 않는다. (#64)
- 키 목록이 키마다 TYPE·TTL을 따로 보내던 것(최대 4,000번 왕복)을 500개씩 묶어 파이프라인으로 보낸다. (#64)
