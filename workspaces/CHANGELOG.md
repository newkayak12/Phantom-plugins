# Phantom Workspaces 변경 이력

## 미배포

## 0.7.7 (2026-11-27)

- 저장소 하위 폴더에서 연 프로젝트도 그 저장소의 체크아웃으로 묶인다. 홈 폴더의 저장소는 그 아래 프로젝트를 차지하지 않는다. (#174)
- 워크트리 삭제·정리에서 git이 멈추면 1분 뒤 오류로 끝나고, git이 없거나 실행되지 않으면 오류 창으로 알린다. 터미널과 같은 PATH에서 git을 찾는다. (#174)
- Next/Previous Project Window는 프로젝트 탭이 둘 이상일 때만 켜진다. (#174)
- 창을 활성화할 때 그 프로젝트의 체크아웃만 읽고, 여러 창의 Projects and Files 목록이 한 번 읽은 결과를 함께 쓴다. (#174)

## 0.7.6 (2026-11-26)

- Projects and Files 제목 옆에 열린 프로젝트 수가 나온다. (#156)
- IDE 밖에서 지워진 폴더와 워크트리는 Projects and Files에 나오지 않고, 도구 창을 열 때마다 목록을 다시 읽는다. (#156)
- 프로젝트를 바꿀 때 도구 창 배치(위치, 크기, 열린 창)를 앞의 프로젝트에 맞추던 동작을 기본으로 끈다. Settings | Advanced Settings \| Phantom Workspaces에서 다시 켤 수 있다. (#156)

## 0.7.5 (2026-11-26)

- 이미 지워진 폴더를 삭제하려 하면 아무 일도 일어나지 않던 문제를 고쳤다. 그런 폴더는 "Remove from List"로 목록에서 빠지고, 워크트리였다면 git 워크트리 목록에서도 정리된다. (#155)

## 0.7.4 (2026-11-26)

- Projects and Files에서 열려 있지 않은 폴더를 지울 수 있다. 우클릭해 워크트리는 git worktree remove로 지우고(변경이 있으면 git이 거부하고 브랜치는 남는다), 다른 폴더는 휴지통으로 옮긴다. (#152)

## 0.7.3 (2026-11-26)

- Projects and Files 도구 창 아이콘을 Project 도구 창의 폴더 아이콘과 헷갈리지 않게 브랜치 아이콘으로 바꿨다. (#151)

## 0.7.2 (2026-11-26)

- 위쪽 프로젝트 탭 줄을 다시 숨긴다. 열린 프로젝트는 Projects and Files에서 본다. (#150)
- Projects and Files가 Project 보기 안의 한 보기가 아니라 왼쪽의 별도 도구 창이 된다. 프로젝트 창을 열면 한 번 펼쳐진다. Open, New, Clone 버튼은 Home의 편집기 탭에만 있다. (#150)

## 0.7.1 (2026-11-26)

- 위쪽 프로젝트 탭 줄이 돌아왔다. 0.7.0에서 Projects and Files 목록으로 대신하며 없앴던 것이다. (#149)
- 프로젝트 창도 왼쪽에 Projects and Files 목록을 보여 준다. Home에서만 기본이던 보기가 모든 프로젝트 창의 기본이 되고, 다른 보기를 기억한 프로젝트도 처음 열 때 이 목록으로 연다. (#149)

## 0.7.0 (2026-11-26)

- 위쪽 프로젝트 탭 줄 대신 Project 도구 창의 Projects and Files 보기가 열린 프로젝트와 최근 프로젝트를 저장소별로 보여 준다. worktree는 기본 체크아웃 아래에 들여쓰기로 붙고, 열지 않은 worktree도 `.git/worktrees`에서 읽어 나온다. 눌러서 전환하거나 탭으로 열고, ×로 닫고, 이름·경로·브랜치로 찾는다. (#147)
- 열린 프로젝트가 없으면 모달 환영 창 대신 Home이 프로젝트 창으로 열린다(IntelliJ의 non-modal welcome screen). Home에서 연 프로젝트는 그 창을 이어받고, 마지막 프로젝트를 닫으면 그 자리에 Home이 돌아온다. Phantom Workspaces를 끄거나 지우면 예전 환영 창이 돌아온다. (#147)
- 같은 git 저장소의 기본 체크아웃과 worktree 탭이 나란히 놓이고, 둘 이상 열려 있으면 브랜치 이름을 제목으로 쓴다. 기본 체크아웃에는 집 아이콘이 붙는다. (#132)
- 프로젝트 탭 설정을 끄면 IDE 전체의 AWT 계층 이벤트 리스너도 해제한다. 꺼 둔 동안 창의 컴포넌트가 바뀔 때마다 계층 이벤트가 만들어지지 않는다. (#115)
