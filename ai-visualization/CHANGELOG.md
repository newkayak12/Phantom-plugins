# Phantom AI Visualization 변경 이력

## 미배포

## 0.6.5 (2026-11-27)

- 열린 AI Visualization 탭과 도구 창이 데이터 읽기와 모델 만들기를 한 번만 공유하고, 모델은 백그라운드 스레드에서 만든다. (#PR)
- worktree 목록을 캐시해 세션 이벤트마다 git을 실행하지 않고, 저장소 매핑이 바뀌거나 worktree가 바뀌었을 때만 다시 읽는다. (#PR)
- 그린 내용이 같은 장면은 방 이미지를 다시 합성하지 않는다. 화면 문구를 메시지 번들로 옮겼다. (#PR)

## 0.6.4 (2026-11-26)

- AI Visualization 탭이 가려져 있는 동안에는 세션 이벤트마다 다시 읽지 않고, 다시 보일 때 읽는다. 한 번 읽을 때 프로젝트마다 worktree 목록을 한 번만 가져온다. (#114)
- 도구 창 스트라이프 아이콘을 계층도 대신 모니터 앞의 사람(일하는 에이전트) 그림으로 바꿨다. (#112)
