# Support for Kubernetes 변경 이력

## 미배포

## 0.6.4 (2026-11-27)

- 매니페스트 사이 거터를 느린 패스에서 계산해 파일을 처음 열 때 프로젝트의 YAML을 모두 읽지 않는다. 프로젝트 매니페스트 캐시는 PSI 대신 이름·레이블과 스마트 포인터만 보관한다. (#PR)
- Helm 차트의 `define`·`include` 목록과 의존성 여부를 차트마다 한 번 읽어 캐시한다. 완성, 이동, 검사, 거터가 매번 템플릿을 모두 다시 읽지 않는다. (#PR)
- `{{/* … */}}` 주석 안의 `.Values`와 `include`를 검사하지 않는다. (#PR)
- 서브차트 값을 잘못 경고하지 않는다: 부모 템플릿의 `.Values.<서브차트>.*`는 서브차트 values.yaml에서, 서브차트 템플릿의 값은 부모 values.yaml의 `<서브차트>:` 아래에서도 찾는다. (#PR)

## 0.6.3 (2026-11-26)

- 표시 이름을 바꿨다: Phantom for Kubernetes → Support for Kubernetes. 플러그인 id와 기능은 그대로다. (#136)
- 매니페스트 사이 거터가 키마다 파일 전체를 다시 읽지 않고, 프로젝트 매니페스트 목록은 YAML이 바뀌거나 파일이 생기고 지워질 때만 다시 읽는다. Java 등 다른 언어를 입력해도 다시 읽지 않는다. (#119)

## 0.6.2 (2026-11-22)

- 이름을 바꿨다: Kubernetes Support → Phantom for Kubernetes. Phantom으로 시작하고, 지원하는 프로젝트 이름은 뒤에 둔다. 플러그인 id와 기능은 그대로다.
