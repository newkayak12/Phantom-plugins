Reports {{- at the start of a line whose action writes text. The dash removes the line break before the action, so its output is appended to the previous line: image: followed by a line {{- .Values.image }} renders as image:nginx, which is no longer a key with a value. Control actions (if, range, with, end), assignments, comments and pipelines ending in nindent are not reported, nor actions after another template line. Helper files (_helpers.tpl) are skipped.
