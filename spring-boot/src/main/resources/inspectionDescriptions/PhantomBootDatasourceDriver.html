Reports spring.datasource.url (or spring.datasource.hikari.jdbc-url) whose JDBC vendor, such as jdbc:mysql: or jdbc:postgresql:, has no driver anywhere on the project's classpath. Spring Boot then fails at startup because it cannot load the driver class.

The driver is looked up in every module and library of the project, so a runtimeOnly driver in another module is accepted. When spring.datasource.driver-class-name is set in the same file, that class is checked instead. URLs built from placeholders and unknown vendors (Testcontainers' jdbc:tc:, P6Spy) are skipped.
