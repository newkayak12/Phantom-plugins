# Phantom Navigation Bar

`dev.phantom.navbar` · [한국어](./KOR.md)

The navigation bar: the path of the current file above or below the editor (View | Appearance | Navigation Bar), with popups to browse and open files, and Alt+Home to jump into it.

Based on the IntelliJ Community Navbar plugin (Apache 2.0), under Phantom's own id. `intellij.navbar.plugin` stays as an alias and the
content module names stay the IntelliJ ones, so the platform modules and plugins that depend on them keep working.
Phantom bundles this build instead of the IntelliJ plugin.
